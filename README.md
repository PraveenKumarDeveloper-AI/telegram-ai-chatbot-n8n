# 🤖 Telegram AI Chatbot with n8n

An AI-powered Telegram chatbot built with **n8n, Telegram, OpenAI, Simple Memory, and Gmail**.

## 🚀 Workflow

```text
Telegram User
      ↓
Telegram Trigger
      ↓
AI Agent
   ↙      ↘
OpenAI   Simple
Model    Memory
   ↘      ↙
    AI Response
        ↓
Telegram Send Message
        ↓
   Telegram User
